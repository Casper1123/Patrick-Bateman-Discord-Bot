# Admin Commands
Administrators get access to a small suite of commands. Below are short descriptions of what they do and how they work.

## Preferences
For either individual channels or all channels in the server, certain autoreply features can be disabled. Check the options and descriptions on how they work.

## Pausing
You can pause all autoreply features temporarily in a given channel, or all channels. This will run out automatically.

## Facts
using `/add`, you can add a *local* fact (for your server only). This uses the P.I.S.S. system for extra customizability.
You can find out more about P.I.S.S. [here](https://github.com/Casper1123/Patrick-Bateman-Discord-Bot/blob/main/piss/README.md) or on the [wiki](https://github.com/Casper1123/Patrick-Bateman-Discord-Bot/wiki). Given facts can be modified using `/edit`, removed using `/delete` and obtained all in one go using `/index`. You can preview and test-compile your P.I.S.S. input using `/preview`.

## Logging
using `/log` you can set a channel for logging output. This mostly pertains to channel preferences and fact edits.
If Patrick somehow loses access to this channel, logging is disabled.
